Code for Experiment in Publication “Synthetic Method of Analogues for Emerging Infectious Disease Forecasting”
========

All code used to perform the experiment in the cited publication.  For questions, issues, or clarifications please reach out to Murph: <murph@lanl.gov>.

## Running the sMOA Experiment

### Requirements
- **SLURM environment**: The main experiment script [perform_smoa_experiment.sh](perform_smoa_experiment.sh) requires a SLURM job scheduler for parallel execution across US states
- **R environment** with required packages (see [R/run_smoa.R](R/run_smoa.R) for dependencies)
- **Compute cores**: 53 cores allocated by SLURM (script uses 12 cores internally for parallel processing)

### Required Input Data Files

The [R/run_smoa.R](R/run_smoa.R) script requires the following data files in the [data/](data/) directory:

#### Files tracked in git:

1. **`hub_locations.rda`, `hub_locations_flusight.rda`, `hub_locations_ecdc.rda`** - Location metadata (~67KB total)
   - These files are **directly downloaded from the covidHubUtils repository** due to local compute node issues
   - Download from: https://github.com/reichlab/covidHubUtils/tree/master/data
   - Place in [data/](data/) directory
   - Already included in this repository

2. **`state_truths/`** directory - Pre-computed state-level truth data
   - Contains one `.RData` file per US state (e.g., `Alabama.RData`, `Alaska.RData`, ...)
   - Already included in this repository

#### Files that must be generated (too large for git):

3. **`scores_tot_w_wis_components.csv`** (~100MB) - Model scores with Weighted Interval Score (WIS) components
   - **REQUIRED**: Must be generated before running the experiment
   - Generated by running [R/get_model_scores.R](R/get_model_scores.R)
   - [R/run_smoa.R](R/run_smoa.R) will automatically generate this file if missing (but this adds significant runtime)
   - **Recommended**: Generate this file once before submitting SLURM jobs

4. **`tdat_list_tot_weekly.csv`** (~5.5GB) - Weekly COVID-19 truth data 
   - **REQUIRED**: Must be generated before running the experiment
   - Historical observed case/death data for validation
   - Generated by running [R/get_data_as_of.R](R/get_data_as_of.R)
   - [R/run_smoa.R](R/run_smoa.R) will automatically generate this file if missing (but this adds significant runtime)
   - **Recommended**: Generate this file once before submitting SLURM jobs

#### First-time setup:

```r
# Run these once to generate the large required data files
source("R/get_model_scores.R")    # Creates scores_tot_w_wis_components.csv (~100MB)
source("R/get_data_as_of.R")      # Creates tdat_list_tot_weekly.csv (~5.5GB)
```

**Note**: These data generation scripts may take considerable time to run as they make API calls to fetch historical COVID-19 data and model forecasts.

### Running the Experiment

```bash
cd smoa
sbatch perform_smoa_experiment.sh
```

The script will:
1. Create output directories (`SLURMOUT/`, `logfiles/`) if they don't exist
2. Load the R module
3. Execute [R/run_smoa.R](R/run_smoa.R) via `R CMD BATCH`
4. Generate log files in `logfiles/smoa_by_state_*.Rout`

### Output Data Files

[R/run_smoa.R](R/run_smoa.R) generates the following logged data files (these are **not** tracked in git):

- **`data/dispersion_logs/`** - Dispersion parameter estimates per state
- **`data/embeddings_by_location/`** - Embedding matrices (X, y) per state
- **`data/coverage_data/`** - Prediction interval coverage statistics per state
- **`data/early_pandemic_forecasts/`** - Early pandemic forecast data per state
- **`data/synthetic_logs/`** - Synthetic curve generation results
- **`data/k_5_num_curves_*/`** - Final sMOA forecasting results per state

These output files are used by the figure generation scripts in [R/figure_*.R](R/).
