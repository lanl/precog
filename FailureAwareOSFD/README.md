# epiOutputExpansion

Output-space filling design for black-box simulation experiments via sequential design with expected improvement (EI) acquisition.

## Overview

This R package implements constrained output-space filling design (OSFD) for epidemiological simulations where traditional input-space designs fail to produce diverse outputs. The method uses sequential design with Gaussian process modeling and expected improvement acquisition to explore the output space efficiently.

**Key features:**
- Output-space expansion via sequential design with EI acquisition
- Feasibility modeling for black-box simulations that may fail
- Efficient candidate scoring and batch selection
- Parallel evaluation with retry logic
- Support for complex epidemiological simulators (SIR, SMOA, MutAntiGen)

## Core Method

The main function is `constrained_osfd_ei_with_retry()` in `R/constrained_osfd_ei_with_retry.R`:

```r
constrained_osfd_ei_with_retry(
  f,              # Black-box simulator function
  p,              # Input dimension
  q,              # Output dimension
  CAND,           # Candidate design matrix
  n_success,      # Target number of successful runs
  n_ini_success,  # Initial random samples
  batch_size,     # Parallel batch size
  ...
)
```

The method:
1. Initializes with random successful evaluations
2. Fits GP models to predict output diversity
3. Scores candidates using EI acquisition function
4. Selects diverse batches using repulsion
5. Evaluates candidates in parallel with retry logic
6. Updates models and repeats until target achieved

## Reproducing Paper Figures

**System Requirements:** This repository uses SLURM for job scheduling on HPC systems.

### Complete Figure Generation Guide

**Figures 1, 2, and 8** - Wang method extension (automated pipeline):
```bash
sbatch run_wang_figures.sh
```
This executes:
1. `R/01_reproduce_wang_inverse_radius.R` - Reproduces Wang et al. (2024) inverse-radius OSFD
2. `R/03_failure_stochastic_inverse_radius.R` - Extends with simulator failures and stochasticity
3. `R/04_plot_wang_extension_experiment.R` - Generates figures

Outputs:
- `viz/failure_stochastic_diagnostic_scatter.png` (Figure 1)
- `viz/failure_stochastic_extension_metrics.png` (Figure 2)
- `viz/wang_reproduction_metrics.png` (Figure 8, appendix)

**Figure 3** - SIR output-space emulation (n=100,000):
```bash
sbatch --export=NSUCCESSES=100000 sir_output_run.sh
```
Output: Generated by `emulation_experiment.R` → `viz/emu_mae.png`

**Figure 4** - Grid coverage densities across sample sizes:
```bash
# Run sir_output_run.sh at multiple sample sizes
for n in 25 50 75 100 150 200 300 500 1000 2000 3000 4000 5000; do
  sbatch --export=NSUCCESSES=$n sir_output_run.sh
done

# After all jobs complete, generate Figure 4
Rscript R/plot_grid_coverage_densities.R
```
Output: `viz/grid_coverage_densities.png`

**Figure 5** - Emulation experiment (requires Figure 4 data):
```bash
# Run after completing all sir_output_run.sh jobs above
Rscript R/emulation_experiment.R
```
Output: `viz/emu_mae.png`

**Figure 6** - Stochastic SIR comparison:
```bash
sbatch run_stochastic_sir_all.sh
# After job completes, generate plot
Rscript R/plot_stochastic_sir_experiment.R
```
Output: `viz/stochastic_sir_experiment.png`

**Table 1 and Figure 7** - SMOA synthetic method comparison:
```bash
./run_smoa_pipeline.sh
```
Outputs: `viz/smoa_performances.png`, `viz/performance_boxplots.png`, and others

**Supplemental Figure 9** - SIR feasibility in PIV-PIT space:
```bash
Rscript R/testing_feasibility.R
```
Output: `viz/sir_feasibility_pivpit.png`

**Computational requirements:** Most experiments use 60-100 cores and 150-200GB RAM. The `run_wang_figures.sh` pipeline runs up to 48 hours. Individual `sir_output_run.sh` jobs complete in ~8 hours.

## Example Experiments

Several example experiments demonstrate the method on different simulators:

- **SIR model** (`run_sir_space_filling.R`): Basic epidemic curve diversification
- **Stochastic SIR** (`run_stochastic_sir_space_filling.R`): Stochastic epidemic dynamics
- **SMOA** (`perform_smoa_using_new_synthetic.R`): Synthetic method of analogues
- **MutAntiGen**: Antigenic evolution and epidemic dynamics (in development)

## MutAntiGen Analysis

Special analysis tools for MutAntiGen simulation outputs:

- `analyze_mutantigen_outputs.R`: Comprehensive analysis computing epidemic peaks, antigenic diversity, mutational load, and population dynamics
- `extract_mutantigen_10_outputs.R`: Fast extraction of 10 key summary statistics for output-space expansion experiments (optimized with vectorized simmap parsing, ~3.7x speedup)

## Installation

This is an R package with Rcpp dependencies:

```r
# Install dependencies
install.packages(c("Rcpp", "RcppArmadillo", "lhs", "foreach", "doParallel"))

# Install from source
devtools::install_local("/path/to/epiOutputExpansion")
```

## Usage

See experiment scripts for detailed examples. Basic workflow:

```r
library(epiOutputExpansion)

# Define simulator function
f <- function(x) {
  # Your black-box simulator
  # Returns vector of outputs or error
}

# Generate candidate pool
CAND <- lhs::randomLHS(100000, p = 3)

# Run output-space filling
result <- constrained_osfd_ei_with_retry(
  f = f,
  p = 3,
  q = 2,
  CAND = CAND,
  n_success = 1000,
  batch_size = 8,
  mc.cores = 8
)
```
